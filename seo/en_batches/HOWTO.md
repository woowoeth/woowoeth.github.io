# 补一批英文条目：怎么写

英文站要和中文站一样完整（159 条）。这份说明是给每一批的写手看的。
**你只写两种文件，其余一个都不碰。**

## 你要交的东西

1. `seo/chapters_en/<py>.py` —— 你负责的每个人一个（`<py>` 是 slug 里的
   `-` 换成 `_`，和 `seo/chapters/` 下中文那个文件同名）。
2. `seo/en_batches/<你的批号>.py` —— 条目记录、一句介绍、处境问句、今日一句。

**不要动**任何共享文件（`en_entries.py` / `hwx_scenes_en.py` /
`quote_asks_en.py` / `hwx_en.py` / `check_en.py`）。不要跑 `build_all.py`、
`gate.py`，不要 commit、不要 push。

## 原文在哪

- 章节：`seo/chapters/<py>.py`（`PARENT` + `CHAPTERS`）。
- 条目记录：项目根 `index.html` 里那个 `const D=[...]`，按 `n:"中文名"` 找。

英文不是翻译，是**为英文读者重写**：同一个事实、同一个论证，用英文读者
自己的语感说。但事实必须忠于原文 —— 人名、年份、书名、数字、故事细节
一律照原文，不要自己发明。

**原话是英文说的，就还原英文原句，不要从中文回译。** 中文站上那句
「Focus 意味着对一百个好主意说不」在英文页上必须是他本人的原话。
凡是外文原著（希腊、罗马、法、德、日、英美），引语用通行英译。

**引号里的字一个都不许改。** 站里的行文是英式拼写（behaviour / organisation），
但那是**我们自己的话**的规矩，不是引语的规矩。把 Meadows 原文的 "behavior"
改成 "behaviour" 以求统一，是在悄悄改动一句引语 —— 引语照原样，哪怕它和
周围的拼写不一致。

**没把握出处的引语一律不用。** 网上流传甚广 ≠ 有出处，爱因斯坦、丘吉尔、
马克·吐温名下的伪引语尤其多。想不起是哪一章哪一页，就换一句想得起来的；
换不出来就少放一句（每章至少 2 句即可）。英文读者一次搜索就能查，
挂一句查不到出处的，整页的可信度都跟着掉。

## `seo/chapters_en/<py>.py` 的形状

```python
# -*- coding: utf-8 -*-
"""<英文名> — English.

两三句：英文读者带着什么先入之见来到这一页，这一页要做的是哪件不一样的事。
"""

PARENT = {
    "name": "<英文名，见 seo/en_names.py>",
    "slug": "<slug>",
    "blurb": "Deep read",
    "items": [                       # 必须覆盖下面每一章，一章一条
        {"k": "<章key>", "n": "<章标题>", "w": "<副题>", "ready": True,
         "line": "<卡片上那一行，一句话，别用句号结尾>"},
    ],
}

CHAPTERS = [
    {
        "k": "<章key，必须和中文那边一模一样>",
        "n": "<章标题>",
        "w": "<副题：一句话说清这一章的主张>",
        "src": "<出处，照中文那条译过来>",
        "dek": "<12-30 词。这一篇要回答的是什么>",
        "story":
            "<50-110 词。一个具体场景，中间有且只有一处 ==这样标出来的强调==>",
        "f": [                       # 至少 2 段，一般 3 段
            {"n": "<小标题>",
             "d": "<20-55 词。这一段的道理>",
             "eg": "<8-40 词。一个具体的、今天的例子>"},
        ],
        "q": [                       # 至少 2 句，一般 3 句；每句 ≤14 词
            "<值得记住的一句>",
        ],
        "apply":
            "Where you are: <读者此刻的局面>\n"
            "Ask first: <该先问自己的那一句>\n"
            "Where it goes wrong: <这条道理最常被用反的地方>",
    },
]
```

## `seo/en_batches/<批号>.py` 的形状

```python
# -*- coding: utf-8 -*-
"""<分类> 第 N 批：<人名列表>。"""

ENTRIES = [
    {
        "c": "<分类，见 en_names.py>", "n": "<英文名>", "slug": "<slug>",
        "e": "<年代，如 Tang · 598–649>", "w": "<一个词的主题>",
        "y": <代表年份，公元前用负数>,
        "d": "<这个人是谁、他的核心主张是什么。三到五句>",
        "story": "<一个具体场景。**不能和任何一章的 story 是同一个场景**>",
        "f": [{"n": "...", "d": "...", "eg": "..."}, ...],   # 3-5 段
        "apply": "<读者今天可以做的一件具体的事>",
        "q": ["<三句左右>"],
        "l": ["<相关的人，写名字不写 slug>"],
        "contrast": [{"n": "<某个人>", "why": "<两人在哪一点上正好相反>"}],
    },
]

INTROS = {"<slug>": "<一句话介绍，英文读者多半不认识这个名字>"}

SCENES = [
    ("<处境名>", "<分组名>", [
        ("<读者会说出口的那句话>", [("<slug>", "<章key>")]),
    ]),
]

ASKS = {"<slug>/<章key>": "<今日一句>"}

SC_BOX = {"<处境名>": "<预填句>"}      # 只有**新开**的处境才需要
SC_SHORT = {"<处境名>": "<短名>"}      # 处境名超过 20 个字符时给一个
```

## 十条会被闸门拦下来的事

1. **章 key 必须和中文那边逐字相同。** 门禁拿中文当「这一版的计划」，
   key 对不上会被报成「写了但不在计划里」。
2. **名字和分类照 `seo/en_names.py`。** 名字是接口不是内容 —— 别的批次
   会照契约引用你，各起各的名字会让交叉链接当场断掉。
3. **长度：** dek 12-30 词、story 50-110 词、每段 d 20-55 词、eg 8-40 词、
   每句金句 ≤14 词。英文一个词≈一个信息单位，汉字一个字就是一个 ——
   同样的框，英文装不下同样多的话。第一稿几乎一定超，别硬塞，删。
4. **story 里有且只有一处 `==强调==`；条目记录里一处都不能有**
   （条目页不渲染它，带进去就是页面上两个字面的等号）。
5. **条目的 story 不能是任何一章的 story。** 条目页是引子，章节是论证；
   同一个场景讲两遍，读者会觉得这个站在原地打转。
6. **今日一句（ASKS）必须和某条处境问句逐字相同**，包括标点。
   它就是那句问句，不是另写一句。
7. **每一章都要有一条处境问句指着它**，一条都不能漏。
8. **优先挂到已有处境下**（`scripts/hwx_scenes_en.py` 里有 84 个）。
   新开处境要给 `SC_BOX` 预填句，而且**预填句不能是问句的复述** ——
   两者在页面上相距三厘米，构建时有硬断言查重。
9. **`l` 和 `contrast` 只能写 `en_names.py` 里有的名字**，或者已经上线的
   那 40 条。指向没有英文页的人 = 把读者送去中文页。
10. **英文页上不许出现中文**，包括标点（，。、；：？！）和中文引号。

## 自检

```
python3 scripts/check_batch.py <你的批号>
```

几秒钟跑完，不起服务不开浏览器。**改到它全绿为止**，然后回报你做了什么。
它绿了不等于完整门禁绿（还有渲染层的判据），但它红了就一定过不去。
